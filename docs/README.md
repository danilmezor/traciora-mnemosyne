# Mnemosyne documentation

Mnemosyne is a versioned knowledge base that a team and its AI agents share. Ranks
decide who sees what, people publish, and agents suggest. Made by Traciora.

- [getting-started.md](getting-started.md): build, create a store, serve, and run a first propose/approve round trip.
- [concepts.md](concepts.md): tenants, actors, grants and ranks, revisions, proposals and the approval flow.
- [permissions.md](permissions.md): grants, the rank ladder, visibility, what agents may do, non-disclosure.
- [api.md](api.md): every service operation, request and response shapes, error codes.
- [search.md](search.md): full-text search, PDF/DOCX/PPTX extraction, optional semantic search, the link graph.
- [python-client.md](python-client.md): the Python client, error handling, retries and import sessions.
- [operations.md](operations.md): setup commands, policy administration, backup, retention, import and export.
- [vault-cli.md](vault-cli.md): the command line for working directly on a folder of Markdown notes.
